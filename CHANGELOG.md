# Changelog

## 1.1.0

### More versions and loaders
- Now available on **Fabric** and **NeoForge** for Minecraft **1.21 – 1.21.11** and **26.1 – 26.3**
- One file per loader covers each range: 1.21 – 1.21.1, 1.21.2 – 1.21.11 and 26.1 – 26.3

### New
- **Eyeblossom hedges** (1.21.4 and later) that open at night and close during the day, like real eyeblossoms
- **Golden dandelion hedges** (26.1 and later)
- Hedges can be composted

### Changes
- Flowering hedges break faster with a hoe, like plain hedges
- Middle-clicking a flowering hedge now gives a hedge
- Shears from other mods can snip flowers off hedges too

### Fixes
- Fixed the hedge recipe not loading on 1.21.1, so hedges can be crafted again
- Flowering hedges are now shaded like plain hedges instead of looking brighter
- Fixed a black plane inside hedges standing on solid blocks
