# Simple Hedge Mod

A mod that adds a custom vanilla styled hedge block with special traits and flowering variants!

## Features

- Hedges look 1.5 blocks tall but are only one block tall physically, so they stack into seamless hedge walls. Place them under other blocks for a mossy look, like a fallen log taken over by moss.
- Right-click a hedge with a flower to turn it into a flowering hedge, like with flower pots. Snip the flower back off with shears, or break the hedge to get both back.
- Bees can collect pollen from flowering hedges.
- Crouch while walking into a hedge to pass through it. Create secret entrances, or traps for your enemies. Be careful with hedges that have wither roses on them!
- Torchflower hedges glow, and eyeblossom hedges open at night and close during the day like real eyeblossoms.

Flowers that go on hedges: dandelion, poppy, blue orchid, allium, azure bluet, all four tulips, oxeye daisy, cornflower, lily of the valley, wither rose, torchflower, golden dandelion (26.1 and later) and both eyeblossoms (1.21.4 and later).

## Crafting

Surround a stick with any type of leaves to make four hedges.

## Compatibility

- Minecraft: Java Edition 1.21 to 1.21.11 and 26.1 to 26.3
- Loaders: Fabric and NeoForge
- Environment: client and server
